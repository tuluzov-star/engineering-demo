# Engineering Demo Roadmap

## Phase 1 — Foundation (implemented in this starter)

- WordPress + WooCommerce backend
- custom read-only REST endpoint
- Next.js 16 App Router frontend
- WooCommerce Store API product catalogue
- repeatable demo product seeding
- Docker Compose local environment
- CI quality gate

## Phase 2 — Commerce flow

- Store API cart
- add/remove/update line items
- cart token and nonce handling
- checkout fields
- order creation
- HPOS verification
- error states and retries

## Phase 3 — Engineering depth

- PHPUnit for the WordPress plugin
- frontend component/unit tests
- Playwright end-to-end smoke tests
- structured logging
- health/readiness probes
- caching and revalidation strategy

## Phase 4 — Delivery

- production Docker topology
- reverse proxy and HTTPS
- GitHub Actions deployment
- rollback workflow
- release tags and changelog

## Phase 5 — Portfolio proof

- architecture diagram
- short demo video
- public README screenshots
- documented trade-offs
- performance measurements
- one real business integration extracted from an existing WordPress/WooCommerce project
